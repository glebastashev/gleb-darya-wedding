# Свадебное приглашение Глеба и Дарьи

Интерактивное приглашение на свадьбу 10 октября 2026 года в Wine Time Restaurant, Алматы.

## Публичная ссылка

<https://glebastashev.github.io/gleb-darya-wedding/>

## Персональные ссылки

Основной формат:

```text
https://glebastashev.github.io/gleb-darya-wedding/anna-ivanova
```

GitHub Pages перенаправит такую ссылку на приглашение и подставит имя гостя. Пока имя формируется из адреса автоматически. После получения списка гостей можно добавить точные обращения для семей, пар и компаний.

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm test
npm run build
npm run test:sites
```

Музыка подключена через официальный YouTube-ролик George Michael и стартует примерно с 48-й секунды после открытия конверта. Браузер гостя может потребовать дополнительное нажатие на кнопку звука.
